# ✅ Todo App API (FastAPI)

A simple yet practical Todo App REST API built with FastAPI.  
This project is my first FastAPI experience, designed to demonstrate core backend skills and clean API design.

## 🚀 Features
- Create, read, update, and delete todos (CRUD)
- Fast and async API powered by FastAPI
- Request/response validation with Pydantic
- Auto-generated API docs (Swagger & ReDoc)
- Clean and scalable project structure

## 🛠 Tech Stack
- Python
- FastAPI
- Pydantic
- Uvicorn

## 🎯 Purpose
This project is built to:
- Practice backend API development with FastAPI
- Showcase my understanding of RESTful APIs
- Serve as a foundation for more advanced features (auth, database, testing, etc.)
